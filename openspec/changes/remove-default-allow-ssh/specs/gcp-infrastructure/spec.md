## ADDED Requirements

### Requirement: インターネットからのSSHはどのルールでも許可しない
システムは、ターゲットタグの有無にかかわらず、このVMに適用されるすべてのファイアウォールルールにおいて、`0.0.0.0/0`からの22番を許可してはならない(SHALL NOT)。管理アクセスは、tailnet経由またはIAPの送信元範囲(`35.235.240.0/20`)からに限らなければならない(SHALL)。

#### Scenario: 公開IPの22番に到達できない
- **WHEN** インターネット上の端末からVMの静的External IPの22番へ接続する
- **THEN** 接続は確立せず、タイムアウトする

#### Scenario: IAP経由のSSHは成功する
- **WHEN** 権限を持つ主体が`gcloud compute ssh --tunnel-through-iap`で接続する
- **THEN** 新規の接続が確立できる

## MODIFIED Requirements

### Requirement: 公開ファイアウォールは80/443のみ
システムは、このVMに紐づくファイアウォールルールにおいて、インターネット全体(`0.0.0.0/0`)からのインバウンド接続を80番・443番ポートのみに制限しなければならない(SHALL)。SSH(22番)は、IAPの送信元範囲(`35.235.240.0/20`)からに限って許可してもよい(MAY)。それ以外の送信元に22番を許可してはならない(SHALL NOT)。

#### Scenario: このVM向けルールが80/443のみを許可する
- **WHEN** このVMのタグに紐づくファイアウォールルール一覧を確認する
- **THEN** 送信元が`0.0.0.0/0`のルールが許可するポートは80と443のみである

#### Scenario: 22番の送信元はIAPの範囲に限られる
- **WHEN** このVMのタグに紐づくルールのうち、22番を許可するものを確認する
- **THEN** その送信元は`35.235.240.0/20`のみである
